
# izzyGaming - Responsive Multi-Step Form

This is a fully responsive, multi-step subscription form built with HTML, CSS, and Vanilla JavaScript. The project features a clean, modern design with a creative welcome screen, client-side validation, and dynamic content updates.

**[View Live Demo](https://izzygaming.netlify.app/)** 👈 

-----

## About The Project
The goal of this project was to create a seamless and intuitive user experience for a complex process like signing up for a subscription plan.

The form guides the user through several steps: personal information, plan selection, add-ons, and a final summary, ensuring all data is validated along the way.

-----

## ✨ Features

  - **Creative Welcome Screen:** A branded entry point that smoothly transitions into the main form.
  - **Multi-Step Interface:** Breaks down the subscription process into logical, easy-to-manage steps.
  - **Fully Responsive Design:** Adapts perfectly to desktop, tablet, and mobile screen sizes.
  - **Client-Side Validation:** Provides real-time feedback for required fields and correct email/phone formats.
  - **Dynamic Plan Selection:** Users can switch between monthly and yearly billing, with all prices on the page updating instantly.
  - **Interactive Elements:** Custom-styled checkboxes, radio-like plan cards, and a toggle switch enhance the user experience.
  - **Confirmation Summary:** A final review step allows users to double-check their selections and the total cost before confirming.

-----

## 🛠️ Tech Stack

This project was built using core front-end technologies, with no external libraries or frameworks.

  - **HTML5:** For the structure and content of the form.
  - **CSS3:** For all styling, including Flexbox for layout, custom properties for theming, and keyframe animations for transitions.
  - **Vanilla JavaScript:** For all logic, including DOM manipulation, event handling, state management, and form validation.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You just need a modern web browser like Google Chrome, Firefox, or Microsoft Edge.

### Installation

1.  Clone the repository to your local machine:
    ```sh
    git clone https://github.com/your-username/izzyGaming-form.git
    ```
2.  Navigate to the project directory:
    ```sh
    cd izzyGaming-form
    ```
3.  Open the `index.html` file in your browser to view the project.
